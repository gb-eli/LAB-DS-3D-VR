PAINEL CONTEXTUAL

Holo Sandbox

v2.1.0

Manipulação holográfica 3D.

Pinça ou mão fechada segura o objeto. Duas mãos alteram a escala. A rotação do punho gira o holograma.

P1 0P2 0

Com duas pessoas, cada jogador coleta as formas marcadas com sua cor usando os punhos rastreados pelo esqueleto.

Pinça desenha. Mão fechada apaga. Deslizar para a esquerda desfaz; para a direita troca a cor.

O sistema compara ângulos de ombros, braços, quadril e pernas. Mantenha a pose até completar o indicador.

O laboratório reconhece mão aberta, fechada, pinça, apontar, vitória, positivo, orientação vertical, horizontal e movimentos rápidos.
