Como priorizar a GPU NVIDIA no Windows
  1. Abra Configurações do Windows → Sistema → Tela → Gráficos.
  2. Adicione Chrome ou Edge e escolha Alto desempenho.
  3. Confirme em chrome://gpu se WebGL está acelerado por hardware.
  4. Reinicie o navegador e execute o benchmark novamente.

Por segurança, uma página Web não pode trocar diretamente entre a GPU integrada e a dedicada. Ela pode solicitar alto desempenho e informar o renderizador que o navegador realmente escolheu.
