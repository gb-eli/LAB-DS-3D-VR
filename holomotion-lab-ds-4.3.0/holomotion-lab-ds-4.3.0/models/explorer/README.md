# Modelos externos do Holo Explorer

O Holo Explorer, introduzido na versão 4.2.0, utiliza modelos procedurais e não depende de arquivos nesta pasta.

Futuros modelos devem ser distribuídos em GLB ou glTF 2.0, com:

- escala e pivô normalizados;
- nomes estáveis;
- materiais reutilizados;
- texturas compactadas;
- níveis de detalhe quando necessário;
- tamanho reduzido para GitHub Pages;
- licença e autoria documentadas.
