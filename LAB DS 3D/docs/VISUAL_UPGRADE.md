# Visual Upgrade 4.5.2

## Holo Blocks

O Holo Blocks é carregado somente quando solicitado e utiliza o mesmo motor Three.js já empregado nos hologramas. Oferece 12 materiais: terra, grama, pedra, areia, água, lava, lama, gelo, cristal, metal, madeira e obsidiana.

### Reações

- Água + lava → obsidiana.
- Terra + água → lama.
- Gelo + lava → pedra.
- Areia + lava → cristal holográfico.

### Controles

- Pinça, OK ou punho: executar ferramenta.
- Duas mãos: zoom.
- Giro do punho: rotação.
- Mouse/toque: construir, remover ou inspecionar.

## Temas gráficos

Neon, Cósmico, Matriz, Âmbar e Minimalista. Os efeitos respeitam o Performance Manager e são reduzidos quando o FPS cai.

## Avatar

Quatro estilos: Holograma, Robô, Cósmico e Armadura. O rastreamento continua usando o esqueleto corporal já existente; a mudança é apenas visual, sem acrescentar uma inferência de IA.
